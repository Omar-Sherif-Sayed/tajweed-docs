## How their content is kept — decided by the author, 2026-11-22

The answer does not say whether their content may be committed to our public repositories as a data file (our other
sources are imported from files kept in `tajweed-backend`, and those repositories are public — a committed file would
let anyone download the whole encyclopedia from us, which is more than "including it in the app"). **The author's
decision: database only, never in GitHub** — so no follow-up question is needed:

1. The backend fetches the content from their API (`hadeethenc.com/api/v1`) and stores it in its own PostgreSQL (not
   public); it refreshes it regularly, so their corrections reach us.
2. The web and the phones get it from our API; the phones keep it on the device to work offline (their answer to
   question 2).
3. **No file of their content in any of our repositories**, and never in a public build artifact or GitHub release —
   the phones receive it inside the store build or from our server.
4. Every fetch records its date, the SHA-256 of what was received and the counts; a short or broken answer is refused
   and the stored content is kept.
5. Tests use mocked API answers with one or two records, never the encyclopedia.
